# Changelog

## Unreleased

- Added native dialog and anchored popover paths, View Transitions for navigation and selection, and reduced-motion-aware scroll reveals.
- Added Theme Studio with shareable settings, sandbox previews, DTCG and Tokens Studio exports, and built-in theme JSON.
- Added collaboration components and transport adapters, keyed table streams, ticker, sparkline, gauge, and a windowed log viewer.
- Added accessibility preferences, light-DOM custom elements, registry files for all blocks, and a documentation verification page.
- Added the separate `@utkristi/ui-mcp` stdio server, generated agent references and the Utkristi ESLint plugin.

- Added `Navbar expandOnScroll` for the dock. Once the page scrolls, the floating dock animates into a flush, full-width bar pinned to the top. The brand and links keep their position, and the animation is off under reduced motion. In plain HTML, add `header-expand` to a `.header.header-dock`; `initUI` now toggles `is-scrolled` (also available as `initHeaders`). The docs navbar uses it.

- Marked interactive React modules `'use client'` so they import into Next.js server components; a test keeps new modules marked.
- Added `utkristi-ui.layered.css` and `.layered.min.css`, which wrap the kit in `@layer utkristi.*` so app CSS overrides it without `!important`.
- `@utkristi/ui/tokens` now exports all twelve themes, not only Night, Paper and Glass.
- Docs icon assets are generated by `npm run icons` before `docs` and `docs:build` and are no longer committed. Planning briefs moved to `docs/planning/`. Rewrote the README.
- Added the Theme Engine (`@utkristi/ui/theme-engine` and `npx @utkristi/ui theme`): one brand colour produces a complete theme with OKLCH-solved contrast, a contrast report, and CSS, Tailwind 4 and DTCG exporters.
- Added a native Tailwind CSS 4 entry, `@utkristi/ui/tailwind.css`. The v3 plugin doesn't load under `@plugin` in Tailwind 4, so the README no longer says to use it.
- Added per-component stylesheets under `@utkristi/ui/css/*`, with `core.css` and a manifest.
- Component CSS now uses logical properties and mirrors in right-to-left pages. Code, keyboard keys and sliders stay left-to-right.
- Raised the Vitest timeout to 20 seconds, so the axe and catalog tests don't time out on cold runs.
- Fixed two Next.js App Router build errors found by the new `npm run smoke:next` check. `icons.tsx` used `export *` inside a client module and re-exported `iconGlyphs` twice. The full icon API now comes from a server-safe `icons-entry`.
- Added `scripts/compare-competitors.mjs`, which measures gzipped JS and CSS for six components across Utkristi, MUI, Mantine, React Aria, Radix (shadcn/ui) and Ant Design.
- Redesigned the docs overview in the CoLabs display style. It has a live Theme Engine demo, the measured size comparison and a three-ways-in code switcher.

- Added enterprise application primitives: `Table` / `DataTable` row expansion (`renderExpandedRow`, `expandedRowKeys`), inline cell editing with async `validate` / `onCellEdit`, windowed `virtualize` (`aria-rowcount` / `aria-rowindex`), and `gridNavigation`; `SidebarProvider`, `useSidebar`, `SidebarSection`, and `SidebarDrawer` with `localStorage` persistence; `Fieldset`, `Form`, `useAsyncValidation`, `Calendar` range highlighting, and `DateRangeCalendar` with `locale`, `showTime`, and `useFormReset`; plus `overlayStack` top-down Escape ordering and collision-aware `Popover` `computePlacement`.
- Added automated `axe-core` accessibility tests (`test/a11y.test.tsx`), enterprise interaction tests (`test/enterprise.test.tsx`), performance benchmark suite (`npm run bench`), `MIGRATION.md`, and `SUPPORT.md`.
- Redesigned the landing page (`docs/src/Marketing.tsx`) with an interactive Night/Paper/Glass preview, verified metrics strip, and application primitives grid; fixed `scripts/screenshots.mjs` CSS backdrop check, HTML/CSS/JS sandbox theme/card rendering, and `Pagination` / `DataTable` footer layout.

- Reworked all component reference pages around named usage examples, separate web source files, source-derived API defaults, and searchable sandbox examples.
- Removed decorative colored active edges from workspace navigation, navbar, tabs, and toast.
- Added alert surfaces/actions/dismissal, sidebar collapse modes and edge triggers, vertical and pill tabs, separated accordions, card surfaces, and table striping/borders/empty content.

- Added a Workspace component with trading, terminal, studio, and office layouts, icon-led Navbar navigation, and interactive console, creative, and operations examples.
- Extended 2.5D and raster 3D coverage across the icon catalog and added Microsoft, Adobe, Vercel, Netflix, Figma, and Linear identification marks.

- Added Trading, Snow, Aurora, Sepia, Midnight, Forest, Sunset, High Contrast, and Terminal themes across React, standalone CSS, Tailwind, and the docs. Refined Glass surfaces and added reduced-transparency fallbacks.

- Added separate HTML, CSS, and JavaScript sandbox editors, automatic indentation, and preview error messages.

- Added controlled table views, page-size selection, column visibility, translatable table controls, and scoped control density.

- Added scoped CSS and form submission and reset support for Combobox and DatePicker.
